# Development-only tooling. Nothing here is a runtime dependency of the learning platform.
#
# Setup:
#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements-dev.txt
#
# pypdf        only for tools/verify_source_against_pdf.py, which cross-checks the markdown
#              extraction against the supplied original PDF. That script degrades gracefully if
#              pypdf is absent: it writes a report saying the check was not performed.
# pyyaml       reads the YAML front matter of the lesson files in content/lessons/ when building
#              knowledge/lessons/registry.json (tools/build_content_index.py). There is no
#              graceful degradation here on purpose: without it the registry cannot be built, and
#              the validator will fail rather than let the site show a stale index.
# numpy, sympy for the executable checks behind each lesson (tools/run_content_checks.py). The
#              checks are evidence, not decoration, so these are required to run `make check`.
# The pins below are the versions this repository was checked with on python 3.11.2; the versions
# actually used for the last run are recorded in knowledge/lessons/checks-report.json.
pypdf==6.20.0
PyYAML==6.0.3
numpy==2.4.6
sympy==1.14.0
